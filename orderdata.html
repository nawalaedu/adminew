📊 Order Olah Data

Form pencatatan order pengolahan dan analisis data.

📌 Informasi Order
Silakan lengkapi data order sesuai kebutuhan. ID Order akan dibuat otomatis setelah data berhasil disimpan.
1. INFORMASI ORDER
Masukkan tanggal batas waktu penyelesaian order.
Masukkan nama marketing yang menangani order ini.
Masukkan judul penelitian, judul skripsi, atau judul pekerjaan olah data.
2. KEBUTUHAN ANALISIS
Isi jika software yang dibutuhkan tidak tersedia pada pilihan.
Pilih satu atau lebih software sesuai kebutuhan analisis.
Tuliskan uji atau analisis yang tidak tersedia pada pilihan di atas.
Pilih semua uji atau analisis yang diperlukan.
3. INFORMASI DATA
Masukkan jumlah responden atau jumlah baris data.
4. FILE DATA
Masukkan link Google Drive / OneDrive / penyimpanan file lainnya. Pastikan akses file dapat dibuka oleh tim pengolah data.
5. CATATAN ORDER
